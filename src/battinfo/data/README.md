# Packaged Data

This folder contains the packaged runtime subset of `assets/`, plus generated
profile fragments that are shipped with the Python package.

`samples/` holds the sample data files the tutorials read, such as the NEWARE
cycler export that tutorial 6 converts. They have no other copy in the
repository, so edit them here.

`namespace/` holds the segments that are never record segments (`reserved-segments.json`) and the publisher prefix register (`prefixes.json`, with its JSON Schema). They have no other copy in the repository either.

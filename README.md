# battinfo

BattINFO describes battery cells, tests and datasets as linked records with persistent identifiers, using the EMMO domain-battery ontology.

This release only reserves the package name on PyPI. It installs a module that tells you how to get BattINFO and does nothing else. The first working release on PyPI will be 0.8.0.

Until then, install BattINFO from GitHub:

```bash
pip install "battinfo @ git+https://github.com/BIG-MAP/BattINFO.git"
```

- Documentation: https://big-map.github.io/BattINFO/dev
